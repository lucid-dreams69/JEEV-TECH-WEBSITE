Privacy

Privacy

This website collects nothing about you. Below is exactly what that means.

Summary

The short version

No analytics, advertising, tracking pixels, session recording, or visitor profiling run when you load this website. The site is delivered using standard web infrastructure required to serve a website securely, but it intentionally avoids technologies whose purpose is to observe, profile, or measure visitors.

A company that argues against surveillance should not surveil the people reading the argument. The rest of this page states that precisely, and names the one place where data unavoidably exists.

Not collected

What this site does not do

Cookies
None are set — not essential ones, not optional ones. There is no consent banner because there is nothing to consent to.
Analytics
None, first-party or third-party. No page-view counting, no session recording, no heatmaps.
Trackers
No advertising pixels, no conversion tags, no social embeds that report back.
Third parties
This website does not load third-party analytics, advertising scripts, tracking pixels, social widgets, or session-recording software. The site itself is delivered through standard hosting and DNS infrastructure required to operate a secure website.
Storage
Nothing is written to local storage or session storage on your device.
Forms
There are none. No accounts, no sign-ups, no newsletter.

You do not have to take our word for any of this. Open your browser’s network inspector and reload the page: every request goes to this domain and nowhere else. The drawing below is what you will find.

Unavoidable

The one thing that does exist

To send you a page, a web server has to receive a request, and every request carries an IP address. Our hosting provider keeps standard server logs for security and reliability, as every host does. That is a property of how the web works, not a choice we made, and claiming otherwise would be untrue.

What we choose is what happens next: we do not read those logs to build a picture of visitors, we do not connect them to anything else, and we do not pass them to anyone.

Like every website, requests pass through the infrastructure that delivers the site — hosting, DNS, TLS, and networking. Those systems inevitably process technical request information required to return a page, but they are not used by this website to identify, profile, advertise to, or measure individual visitors.

Email

If you write to us

Mail sent to contact@jeevtech.in reaches a person. We keep the message so that we can reply and so there is a record of the conversation.

Your address is not added to a mailing list, because there is no mailing list. It is not shared, sold, or used to contact you about anything other than the thing you wrote about. If you would like your message and address deleted, ask, and we will do it.

Outbound

Links that leave this site

Links to LinkedIn and Instagram are plain addresses with no tracking parameters attached — we strip them deliberately. Once you follow one you are on that company’s site, under its policy rather than ours, and those companies do collect data.

Scope

This page covers this website only

Servizo is a separate product. It necessarily handles data this website never touches — identity, scheduling, payment records — and it will publish its own policy when it launches. Nothing here should be read as describing it.

Search Console is used only to verify site ownership and understand how the website appears in search results. It does not place analytics code on this website or track individual visitors while they browse.

Questions

Asking us anything about this

Write to contact@jeevtech.in. If you want to know whether we hold anything about you, ask — for this website the answer is almost certainly nothing, and we will say so plainly rather than in paragraphs.

If this page ever changes, the date below changes with it, and the change is described rather than quietly applied.
